3) index.html में नाम पहले से:
   Jyoti Vishwakarma

4) Website में 5 मुख्य steps हैं।
   हर step में 2 photos हैं। एक समय में एक photo दिखती है और दूसरी animation के साथ बाद में आती है।
   इसलिए 10 photos एक साथ नहीं दिखतीं।

5) Design में:
   - dark cinematic background
   - pink/purple/gold aurora
   - 3D floating hearts
   - balloons
   - flowers
   - 5-step navigation
   - अलग-अलग photo animations
   - polaroid memory effect
   - final cake + confetti celebration
   - Jyoti Vishwakarma का नाम
   शामिल है।

6) GitHub Pages पर public करने के लिए:
   - GitHub पर public repository बनाएं
   - index.html को repository के root में रखें
   - images folder और उसकी 10 photos upload करें
   - Settings > Pages
   - Source: Deploy from a branch
   - Branch: main
   - Folder: /(root)
   - Save
   - कुछ समय बाद Visit site दबाएं।

महत्वपूर्ण:
GitHub Pages पर website public होती है। इसलिए केवल वही personal photos डालें जिन्हें आप public internet पर उपलब्ध कराने के लिए तैयार हैं।
